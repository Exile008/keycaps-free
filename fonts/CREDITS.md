All fonts are from Google Fonts, licensed under the SIL Open Font License 1.1.

| File | Family |
| --- | --- |
| inter-bold.ttf | Inter Bold |
| jetbrains-mono-bold.ttf | JetBrains Mono Bold |
| orbitron-bold.ttf | Orbitron Bold |
| bebas-neue.ttf | Bebas Neue Regular |

Chinese legends: no CJK font is bundled (size). Users import one via "Import font", e.g. `C:\Windows\Fonts\simhei.ttf`.
Note: `.ttc` collections (e.g. msyh.ttc) are not supported by opentype.js.
